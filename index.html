Comeback

Stuck? Follow these 5 minutes.

  1. Read the error slowly. The first line says what. The file and line number say where.
  2. Print it. Add console.log() before the broken line. Check what the value really is.
  3. Make it smaller. Delete code until it works. The last piece you deleted is the problem.
  4. Search the exact error in Google or in the official docs.
  5. Ask AI to explain, not to write. Use this prompt: "Explain this error in simple words. Don't give me the full code. Give me one hint."

Being stuck is part of the job. Senior developers are stuck every day. They just have a method.
